# 刘博卓 Max Liu 项目作品集

这份作品集整理了我在加州大学圣克鲁兹分校 Computer Science: Computer Game Design 本科阶段的四项课程项目，展示算法实现、实验分析、交互流程、状态管理和游戏功能开发方面的实践。

[English](README.md)

## P2 终极井字棋 MCTS

**2026年夏季 · CMPM 146 · 个人项目 · Python**

我在课程提供的游戏环境与树节点接口上实现蒙特卡洛树搜索，连接选择、扩展、模拟和回传，并为模拟策略增加立即赢下整盘游戏的行动检查。通过不同预算和策略配置，比较胜负、平局及整批耗时。

[项目说明](projects/p2-mcts/) · [源码](projects/p2-mcts/src/) · [原实验报告](projects/p2-mcts/reports/)

当前归档未包含课程运行框架和完整实验配置；报告中的数据为原提交实验记录。

## Chimera 七天虚拟生物交互体验

**2026年夏季 · CMPM 146 · 三人团队 · HTML CSS JavaScript**

我负责浏览器端游戏框架、七天流程与每日阶段切换、选择历史、状态管理、最终角色展示及模块整合。队友分别负责玩家建模与演化、叙事与视觉方向。项目采用本地规则分析；预留接口不代表已部署外部模型或后端。

[项目说明](projects/chimera/) · [源码快照](projects/chimera/frontend/) · [原仓库](https://github.com/bliu132-art/CMPM146-Final-Project-Chimera) · [试玩](https://bliu132-art.github.io/CMPM146-Final-Project-Chimera/)

## Escape the Card Game

**2026年春季 · CMPM 120 · 三人团队 · JavaScript Phaser**

我负责最终 Joker Boss 和 UI，组织三阶段战斗行为、计时与过渡，并衔接菜单、教程、战斗和结果等场景。玩家升级、大招及精英敌人等由队友负责。

[本人贡献说明](projects/escape-the-card-game/) · [团队源码](https://github.com/IDrinksWaters/CMPM120_escape_the_card) · [试玩](https://idrinkswaters.github.io/CMPM120_escape_the_card/)

## GDevelop 探索解谜游戏

**2025年秋季 · CMPM 80K · 双人团队 · GDevelop 可视化事件**

我负责背包、物品交互与关卡场景，通过条件、动作和变量组织物品拾取、槽位选择、机关触发和区域推进。队友负责角色与角色操作。项目使用原生可视化事件实现，没有将引擎功能描述成个人手写底层代码。

[项目说明](projects/gdevelop-escape-room/) · [原生事件源码](projects/gdevelop-escape-room/source/Game.json) · [原期末演示](https://www.youtube.com/watch?v=w-Y8iY3PGwc)

这里的项目名是描述性名称。公开源码快照未附上来源和再分发条款尚未核实的图片，因此不能作为完整可玩版本；演示视频来自原课程项目记录。
